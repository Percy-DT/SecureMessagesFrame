# FileOrganizerPro (Java)

Overview
FileOrganizerPro is a command-line Java application that automatically organizes files in a directory into folders based on their file types. It helps improve file management by categorizing files such as images, documents, videos, and more.

## Features
- Automatically scans a selected directory  
- Sorts files into categories (Images, Documents, Videos, Audio, Archives)  
- Creates folders for each file type if they do not exist  
- Moves files into the correct folders  
- Simple and fast command-line execution  

##Technologies Used
- Java  
- File Handling (File, FileInputStream, FileOutputStream)  
- Object-Oriented Programming (OOP)  

##Project Structure
- `Main.java` – Entry point of the application  
- `FileOrganizer.java` – Core logic for organizing files  
- `Utils.java` (optional) – Helper methods for file handling  

##How to Run
1. Open the project in NetBeans, IntelliJ, or Eclipse  
2. Compile the project  
3. Run the `Main.java` file  
4. Enter the directory path you want to organize  
5. The program will automatically sort your files
